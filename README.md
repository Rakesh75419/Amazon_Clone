# Amazon Clone

This is a simple Amazon clone made using HTML, CSS and JavaScript.
I created this project for practice and to improve my frontend skills.

In this project I used navbar, image slider, product cards and different
shopping sections similar to Amazon homepage.

## Tech Used
- HTML
- CSS
- JavaScript

## How to Run
Just open `index.html` in browser.

## Note
This is only a frontend practice project.
No backend or real functionality is included.
